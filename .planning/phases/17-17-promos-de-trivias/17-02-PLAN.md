<action>
Create `services/streak_promotion_service.py` with the following methods and implementation:

1. **Class:** `StreakPromotionService`
2. **Constructor:** `__init__(self, db: Session = None)` -- same pattern as `GameService` (line 259 of game_service.py): stores db, creates own session if none provided.
3. **`close(self)`** -- closes session if owns it.
4. **`_generate_code(self, prefix: str = "SK") -> str`** -- generates `{prefix}-{secrets.token_hex(6)}` (result: `SK-a3f8c9e1b2d4` format). Implements D-11 (unique system-wide, enforced by DB unique constraint).
5. **`_pre_generate_codes(self, level: StreakPromotionLevel, prefix: str = "SK")`** -- generates all codes for a level upfront (D-10). Creates `StreakPromotionCode` records with status=AVAILABLE for `level.codes_available` count. Uses `self._generate_code(prefix)`. Logs: `streak_promotion_service - _pre_generate_codes - level_id:{level.id} - count:{count}`.
6. **`create_promotion(self, name: str, description: str, levels: list[dict], duration_mode: str, start_date=None, end_date=None, duration_hours=None, category_id=None, include_general=True, include_vip=False, include_simple=True, created_by=None) -> StreakPromotion`** -- Creates the promotion, creates levels from `levels` list (each with `consecutive_required`, `discount_pct`, `codes_available`), calls `_pre_generate_codes` for each level. Returns the created promotion. Logs: `streak_promotion_service - create_promotion - name:{name} - levels:{len(levels)}`.
7. **`get_promotion(self, promo_id: int) -> StreakPromotion | None`** -- simple DB query.
8. **`get_all_promotions(self) -> list[StreakPromotion]`** -- returns all promotions ordered by created_at DESC.
9. **`get_active_promotions(self, game_type: str = None, category_id: str = None) -> list[StreakPromotion]`** -- returns promotions where `is_active == True` and `status == ACTIVE`. Filters by game_type using the `include_general`/`include_vip`/`include_simple` booleans (maps game_type string 'trivia'->include_general, 'trivia_vip'->include_vip, 'trivia_simple'->include_simple). Filters by category_id if provided.
10. **`_has_claimed_level(self, user_id: int, level_id: int) -> bool`** -- checks Redemption table. Returns True if a redemption exists for this user+level.
11. **`_get_available_code(self, level_id: int) -> StreakPromotionCode | None`** -- finds a code for the level with status=AVAILABLE (not yet delivered).
12. **`claim_for_streak(self, user_id: int, game_type: str, streak: int, category_id: str = None) -> Optional[dict]`** -- Core method. Calls `get_active_promotions(game_type, category_id)`. For each active promo and each level in it, checks:
    - `level.consecutive_required == streak`
    - `not self._has_claimed_level(user_id, level.id)` (D-15)
    - `code := self._get_available_code(level.id)` is not None
    If all pass: marks code as DELIVERED (sets user_id, delivered_at, status='delivered'), creates `StreakPromotionRedemption` record, commits, logs, returns `{'code': code.code_value, 'discount_pct': level.discount_pct, 'promotion_name': promo.name}`. Returns None if no match.
    Logs: `streak_promotion_service - claim_for_streak - user:{user_id} - game_type:{game_type} - streak:{streak} - result:{'claimed' if code else 'none'}`.
    Maximum 50 lines.
13. **`activate(self, promo_id: int)`** -- sets `promotion.is_active=True`, `status=ACTIVE`. If `promotion.category_id` is set, calls `TriviaCategoryService.activate(category_id=promotion.category_id)` (D-08). Logs activation.
14. **`deactivate(self, promo_id: int)`** -- sets `promotion.is_active=False`. If promotion had an associated category, checks if any other active promo uses the same category; if not, calls `TriviaCategoryService.deactivate()` (D-09). Logs deactivation.
15. **`delete_promotion(self, promo_id: int)`** -- deletes promotion (cascade removes levels, codes, redemptions). Also removes any scheduled activate/deactivate jobs from scheduler. Logs deletion.
16. **`pause_promotion(self, promo_id: int)`** -- sets `status=PAUSED`, `is_active=False`. Logs.
17. **`get_redemption_stats(self, promo_id: int) -> dict`** -- returns per-level stats: total codes, delivered count, remaining count (D-13: `codes_available - delivered_count`), list of redemptions.
18. **`get_user_redemptions(self, user_id: int, promo_id: int = None) -> list`** -- returns redemptions for user, optionally filtered by promotion.

**Code generation implementation:**
```python
import secrets

def _generate_code(self, prefix: str = "SK") -> str:
    random_part = secrets.token_hex(6)  # 12 hex characters
    return f"{prefix}-{random_part}"
```

**IMPORTANT:** All methods must be <= 50 lines. Functions that approach the limit should be split. Use `logger.info(f"streak_promotion_service - {method_name} - param:{value} - result:{result}")` pattern for logging.
