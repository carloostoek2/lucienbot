# Plan 17-03: GameService Hook, Admin Handlers, and Registration

**Objective:** Hook StreakPromotionService.claim_for_streak() into all three GameService trivia play methods, create the admin handler file with FSM wizard for creating/managing promotions, and register the new router in handlers/__init__.py, bot.py, and the admin menu keyboard.

**Context:** This plan depends on plan 17-02 (service and scheduler must exist). The hook into GameService is a minimal, single-direction call from GameService to StreakPromotionService -- no coupling in the reverse direction. The admin handlers follow the FSM wizard pattern already established by BroadcastStates, MissionWizardStates, and Phase 16 trivia admin handlers.
