Promociones por Racha
El administrador podrá crear y configurar promociones por racha exclusivas para trivias. Estas promociones son independientes de cualquier otra promoción comercial existente en el sistema.
3.1. Configuración de una Promoción por Racha
Para cada promoción el administrador podrá definir:
Nombre de la promoción.
Niveles de la promoción (cantidad ilimitada de niveles).
Por cada nivel:
Cantidad de preguntas consecutivas correctas requeridas.
Porcentaje de descuento otorgado.
Cantidad de códigos de descuento disponibles para ese nivel.

3.2. Duración de la Promoción
La configuración permitirá definir la vigencia de la promoción de dos formas:
Fechas concretas (fecha y hora de inicio y fin).
Duración relativa (expresada en horas o días a partir de la activación).
3.3. Asociación con Set de Preguntas
El administrador podrá seleccionar un set de preguntas temáticas específico.
Este set se activará únicamente durante la duración de la promoción.
Fuera del período de la promoción, el sistema volverá automáticamente al paquete de preguntas por defecto o al configurado por tema/fecha.
4. Consideraciones Generales
Todas las configuraciones serán gestionadas desde el panel de administración.
Las promociones por racha no afectarán ni se mezclarán con las promociones comerciales existentes.
El sistema deberá validar que los códigos de descuento generados sean únicos. Los códigos no se descuentan cada vez que se despacha uno sino que hasta que el administrador marca como usado un código es cuando se descuenta del número total que se configuró
Se deberá registrar el historial de rachas y códigos canjeados por usuario para evitar duplicidades o abusos.
